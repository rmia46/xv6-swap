# Repository Scripts (`scripts/`)

This directory contains development, testing, and maintenance automation scripts.

## Planned Utilities
- `run_qemu.sh`: Convenience wrapper to run QEMU with specific display or serial redirection options.
- `format_code.sh`: Code formatting check to maintain consistent xv6 style.
- `verify_clean_build.sh`: Runs clean compilation with `-Wall -Werror` to prevent warnings.
