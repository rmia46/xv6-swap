# Source Code (`src/`)

This directory will contain the baseline MIT xv6 operating system source code (kernel, userland utilities, and build system).

---

## Current Status: Pending Starter-Code Integration

> [!IMPORTANT]
> The source tree is intentionally left empty prior to receiving and auditing the official starter code.
> 
> **Why?**
> 1. We must verify whether the starter code is based on xv6-x86 or xv6-riscv.
> 2. We must determine if the instructor has already implemented parts of the swapping framework, page table bit conventions, or stubbed policy hooks.
> 3. We preserve full Git provenance by committing the clean, unmodified starter code on an isolated baseline branch before applying any team modifications.

---

## Post-Receipt Instructions

Once the official archive or repository URL is provided:
1. Conduct the starter audit using [`docs/starter-audit-template.md`](file:///data/rspace/codespace/projects/xv6-swap/docs/starter-audit-template.md).
2. Import the untouched baseline into `src/`.
3. Verify compilation and basic QEMU boot test.
4. Commit the pristine starter snapshot as `chore: import upstream starter code`.
