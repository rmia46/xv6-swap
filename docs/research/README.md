# Research & Policy Studies (`docs/research/`)

This directory houses theoretical research, literature reviews, and algorithmic designs for page replacement policies.

## Key Research Focus Areas
- **FIFO:** Baseline performance, Belady's anomaly risks.
- **Clock (Second Chance):** Hardware `Accessed` (`A`) bit manipulation, hand movement frequency, and sweep overhead.
- **Enhanced Clock (Accessed + Dirty):** Multi-pass categorization `(A, D)` favoring clean page eviction to minimize disk I/O.
- **Adaptive / Predictive Policies:** Dynamic interval decay, working set size estimation, and machine-learning / heuristic adaptive approaches.
