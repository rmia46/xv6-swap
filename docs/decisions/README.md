# Architecture Decision Records (ADRs)

This directory stores all Architectural Decision Records (ADRs) for the CSE323 P4 project.

## Structure
Every ADR documents a significant technical decision, architectural trade-off, or design choice.

Use the numbering scheme `ADR-XXX-<short-title>.md`:
- `ADR-001-template.md`: Template for new decisions
- `ADR-002-target-architecture.md`: Target architecture selection and environment setup
