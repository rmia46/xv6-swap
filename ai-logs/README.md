# AI Experimentation & Query Logs (`ai-logs/`)

To adhere to course requirements and academic integrity guidelines, all interactions with AI systems (e.g. Gemini, ChatGPT, Claude) used for algorithm design, policy ideation, or debugging must be systematically tracked in this directory.

## Requirements
1. Every significant prompt given to an AI must be logged in `ai-logs/prompts/`.
2. The substantive AI response / proposed code / critique must be logged in `ai-logs/responses/`.
3. Code generated or inspired by an AI response must reference the log ID in its commit and PR.

## Directory Structure
- `prompts/`: Timestamped or sequential markdown files containing verbatim prompts.
- `responses/`: Corresponding model responses and team critiques/evaluations.
