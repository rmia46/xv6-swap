# Experiments & Empirical Evaluations (`experiments/`)

This directory houses controlled scientific experiment runs comparing page replacement algorithms under identical system configurations.

## Reproducibility Requirements
Every experiment report must include:
1. Exact git commit hash.
2. Kernel configuration parameters (physical RAM limit, swap space size).
3. Workload configuration.
4. Recorded metrics and conclusion.

See [`template.md`](file:///data/rspace/codespace/projects/xv6-swap/experiments/template.md) to record new experimental trials.
